Reader Connector 隐私政策

更新日期：2026 年 10 月 12 日

Reader Connector 是将用户选中的网页 PDF 论文收录到本机 Reader 桌面应用的 Chrome 扩展。以下说明只针对 Reader Connector。

读取和保存的数据

打开扩展时，它读取当前标签页的标题、网址及论文元数据，并可能读取当前页面正文，以识别可收录的论文。用户点击“收录”并授予网站访问权限后，扩展会读取所选论文页面、PDF 和快照图片。收录内容可能包括页面网址、标题、作者、摘要、DOI、PDF、网页正文及图片，以及用户填写的分类和标签。扩展不会持续记录浏览历史、鼠标操作或按键。

扩展通过 chrome.storage.local 在浏览器本地保存与 Reader 桌面应用连接所需的随机凭据。该凭据由本机 Reader 生成。扩展请求网页和 PDF 时可使用当前浏览器会话，但不会读取或保存网站密码或 Cookie 值。

用途和传输

扩展只为识别论文、下载用户选择的 PDF、补全书目信息，并将收录内容传给本机 Reader。它通过 http://127.0.0.1:17841 与同一台设备上的 Reader 通信。Reader 将导入的 PDF、元数据和经过清理的网页快照保存在本机资料库中。扩展不会把这些内容发送给 Reader 开发者的服务器。

为取得页面、PDF 和快照图片，扩展会向相应网站发出请求；这些网站会按其自身规则处理请求。论文含 DOI 时，扩展可能向 Crossref API 发送 DOI，取得缺失的书目信息。扩展不向 Crossref 发送 PDF、网页快照或 Reader 连接凭据。

共享、保留和删除

扩展不出售用户数据，不将数据用于广告、信用评估或与收录论文无关的用途。扩展本身只长期保存本机连接凭据；移除扩展可删除其浏览器本地存储。已导入的论文和快照由 Reader 桌面应用保存，用户可在 Reader 中删除相应文档。扩展不会在开发者服务器上保留这些内容。

Reader Connector 对通过 Chrome 扩展权限取得的信息，遵守 Chrome Web Store User Data Policy 的 Limited Use 要求。这些信息仅用于扩展向用户提供的论文收录功能及其必要操作；不会用于个性化广告，也不会交由开发者人工阅读，除非用户主动向开发者提供具体材料用于支持。

联系与更新

如有隐私问题，可在 Reader GitHub Issues 联系开发者。请勿在公开 Issue 中附上私人论文、网站凭据或其他敏感信息。若数据处理方式改变，本页会同步更新。

Reader Connector Privacy Policy

Last updated: October 12, 2026

Reader Connector is a Chrome extension that imports PDF papers selected by the user into the Reader desktop app on the same device. This policy covers Reader Connector.

Data accessed and stored

When opened, the extension reads the active tab's title, URL, paper metadata, and possibly page content to identify papers. After the user selects papers and grants website access, it reads the selected pages, PDFs, and snapshot images. Imported data may include URLs, titles, authors, abstracts, DOIs, PDFs, page content, images, folders, and tags. The extension does not continuously record browsing history, clicks, or keystrokes.

The extension stores a random credential generated by the local Reader app in chrome.storage.local to connect to that app. Requests for pages and PDFs may use the current browser session. The extension does not read or store website passwords or cookie values.

Purpose and transfers

The extension uses this data only to identify papers, download selected PDFs, complete bibliographic metadata, and import them into Reader. It communicates with Reader on the same device through http://127.0.0.1:17841. Reader stores imported PDFs, metadata, and sanitized page snapshots in the local library. The extension does not send these contents to a Reader developer server.

The extension requests pages, PDFs, and images from their source websites, which handle those requests under their own policies. If a paper has a DOI, the extension may send the DOI to the Crossref API to retrieve missing bibliographic details. It does not send PDFs, page snapshots, or the Reader connection credential to Crossref.

Sharing, retention, and deletion

The extension does not sell user data or use it for advertising, credit decisions, or purposes unrelated to paper import. The only data persistently stored by the extension is its local connection credential; removing the extension deletes its browser local storage. Reader stores imported papers and snapshots until the user deletes the corresponding documents in Reader. The developer does not retain these contents on a server.

Reader Connector's use of information obtained through Chrome extension permissions complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. The information is used only for the user-facing paper import function and its necessary operations. It is not used for personalized advertising or read by the developer, except when a user voluntarily provides specific material for support.

Contact and changes

For privacy questions, contact the developer through Reader GitHub Issues. Do not post private papers, website credentials, or other sensitive information in a public issue. This page will be updated if data practices change.
